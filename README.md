# Что мы ищем и почему у них есть публичный репозиторий

Перехватив данные улетающие на сайт мы спокойненько вынули применяемы CDN сервис cdn.jsdelivr.net и вот в чем прикол:

Для того чтобы файлы проекта успешно раздавались через cdn.jsdelivr.net с GitHub, репозиторий обязательно должен быть публичным (Public).

Это обусловлено следующими факторами:

Архитектура CDN: Сервис jsDelivr автоматически интегрирован с публичными реестрами (такими как npm и GitHub) и рассчитан исключительно на предоставление доступа к открытому исходному коду (Open Source).

Отсутствие авторизации: У CDN нет механизма для аутентификации пользователей или запроса токенов доступа к приватным репозиториям GitHub. Без публичного статуса репозитория система просто не сможет обратиться к файлам по ссылке вида [https://cdn.jsdelivr.net/gh/user/repo/](https://cdn.jsdelivr.net/gh/user/repo/)...

Значит мы ищем publc репозиторий со статичискими файлами для сайтов ферм которые ты защитил от ддос атаки применив бесплдатные CDN скупердяй )))) лямами тоскает а CDN юзает бесплатный.
